# حساب‌یار

یک حسابداری شخصی فارسی، رایگان و آماده‌ی اجرا روی گوشی با GitHub Pages.

## امکانات

- ثبت درآمد و هزینه با دسته‌بندی و تاریخ
- داشبورد مانده، درآمد و هزینه‌ی ماه انتخاب‌شده
- ایجنت محلی برای فرمان‌هایی مثل:
  - `۸۰ هزار برای قهوه خرج کردم`
  - `حقوق ۱۵ میلیون گرفتم`
  - `گزارش این ماه`
  - `آخرین هزینه‌ها`
  - `موجودی`
- ذخیره‌ی اطلاعات داخل مرورگر گوشی، بدون سرور و بدون کلید API
- خروجی پشتیبان JSON و خروجی CSV قابل باز شدن با Excel
- نصب به‌صورت برنامه روی Android و iPhone از مرورگر
- آماده‌ی انتشار خودکار با GitHub Actions و GitHub Pages

## انتشار از خود گوشی

1. در GitHub یک repository عمومی بساز؛ مثلاً `hesab-yar`.
2. فایل `HesabYar-source.zip` را باز کن و **محتویات داخل پوشه‌ی HesabYar** را upload کن؛ فایل `index.html` باید در ریشه‌ی repository دیده شود.
3. به تب `Actions` برو و اجرای workflow با نام `Deploy HesabYar to GitHub Pages` را تأیید کن.
4. در `Settings > Pages`، گزینه‌ی `Source` را روی `GitHub Actions` بگذار.
5. بعد از سبز شدن workflow، لینک صفحه در همان بخش Pages نمایش داده می‌شود.

## نصب روی گوشی

لینک GitHub Pages را با Chrome یا Safari باز کن. در Android از منوی مرورگر `Add to Home screen` و در iPhone از گزینه‌ی Share سپس `Add to Home Screen` استفاده کن.

## نکته‌ی حریم خصوصی

این نسخه برای رایگان و خصوصی بودن، از مدل زبانی آنلاین استفاده نمی‌کند؛ ایجنت آن یک تحلیل‌گر محلی و قابل اتکا برای فرمان‌های مالی مشخص است. داده‌ها به اینترنت ارسال نمی‌شوند. اگر داده‌های مرورگر پاک شود، اطلاعات هم پاک می‌شود؛ قبل از آن از دکمه‌ی پشتیبان‌گیری استفاده کن.

## ساختار

- `index.html`: رابط کاربری
- `styles.css`: ظاهر واکنش‌گرا و موبایل‌محور
- `app.js`: حسابداری، ذخیره‌سازی و ایجنت محلی
- `manifest.webmanifest` و `sw.js`: نصب‌پذیری و حالت آفلاین
- `.github/workflows/deploy-pages.yml`: انتشار خودکار در GitHub Pages
